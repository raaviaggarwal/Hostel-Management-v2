# 03_BACKEND_API_REFERENCE.md

## Complete Backend API Inventory

This document documents every backend API endpoint discovered in the codebase, including HTTP method, exact path, source file and function, purpose, authentication requirements, allowed roles, input parameters, validation rules, database operations, response structure, error handling, authorization scope, and frontend callers.

### Conventions
- All endpoints mounted under `/api` prefix (from `backend/src/app.js:142`)
- Router prefix established by tracing `router[method]` calls in `backend/src/routes/index.js`
- `ok(res, body, status)` = `res.status(status).json(body)` 
- `fail(res, message, status)` = `res.status(status).json({ message })`
- Auth middleware: `getUser()` extracts JWT from `Authorization: Bearer <token>` header or `req.user` set by middleware
